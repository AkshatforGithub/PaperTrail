--- [1] 2610.01108 | Background
2.1 CODING AGENTS Coding agents resolve software engineering tasks by handling each user request as a session (Jimenez et al., 2024). A session may span several agents, each of which alternates between model calls and tool executions. Throughout the session, agents operate on a persistent workspace: the repository checkout together with its execution environment. The workspace holds the artifacts agents work on, such as repository files, patches, and tool outputs. Unlike conversation history, artifacts are workspace state; in particular, most repository files predate the session and outlive it.
--- [2] 2610.01249 | Introduction
Language-model agents are being developed as persistent systems that remember across conversations, accumulate experience in interactive environments, and act through software interfaces rather than answer a single isolated prompt (Park et al., 2023; Packer et al., 2023; Wang et al., 2024a; Yang et al., 2024b). This shift is practically useful: an agent can carry work across sessions, incorporate environmental or execution feedback, and update a plan as new information arrives. It also makes the agent’s input an evolving event stream. A report can arrive late and describe an earlier state, an instruction can be visible before it takes effect, and a retraction can change what should have been believed about the past.
